# Abid Farooq — Portfolio

Built with React + Vite + Tailwind CSS.

## Run locally
```
npm install
npm run dev
```

## Build for production
```
npm run build
```
Output goes to `dist/`.

## Deploy
- **Netlify / Vercel**: connect this GitHub repo, build command `npm run build`, publish directory `dist`.
- **GitHub Pages**: `npm install gh-pages --save-dev`, add a `deploy` script, then `npm run deploy`.
